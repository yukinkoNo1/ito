# いと UI

家族カレンダーPWA「いと」の表示用UI、モックデータ、状態ギャラリーです。通信、ルーター、永続化は含みません。

## ギャラリーを起動する

リポジトリのルートで依存関係を入れ、Viteを起動します。

```sh
pnpm install
pnpm dev
```

Figma Makeでは開発サーバーが通常 `$PORT`（既定は `8443`）ですでに起動しています。プレビューを開くと `src/App.tsx` から `ui/gallery/Gallery.tsx` が表示されます。

ギャラリー上部の横スクロールする状態切り替えから、ホーム、月、空き時間、設定、予定作成、予定詳細、履歴、ゴミ箱、検索、初回案内、インストール案内の全状態を選べます。右側でライト／ダークも切り替えられます。

## 構成

- `tokens.css` — ライト／ダークと家族色のトークン
- `styles.css` — `rem` ベースの共通スタイル
- `mock.ts` — 家族、予定、祝日のモックデータと型
- `primitives/` — ボタン、入力、糸、予定行、共通下部ナビ
- `screens/` — 各画面
- `sheets/` — 予定作成、予定詳細
- `gallery/` — 390×844の端末ギャラリーと状態切り替え
- `icon.svg` — 通常／maskable兼用のアプリアイコン原稿

## 確認

```sh
pnpm format
pnpm build
```

画面コンポーネントはデータとコールバックをpropsで受け取り、アプリ全体の状態管理やデータ取得を持ちません。
